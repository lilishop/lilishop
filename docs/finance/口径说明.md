# 财务对账与报表口径说明

## 结算单应结金额（billPrice）

与 `Bill` 实体及 `BillServiceImpl.initBillPrice` 保持一致：

```
billPrice = orderPrice - refundPrice
          - commissionPrice + refundCommissionPrice
          - distributionCommission + distributionRefundCommission
          + siteCouponCommission - siteCouponRefundCommission
          + giftCardSubsidy - giftCardRefundSubsidy
          + pointSettlementPrice - pointRefundSettlementPrice
          + kanjiaSettlementPrice - kanjiaRefundSettlementPrice
```

等价于：`billPrice = 入账流水 bill_price 合计 - 退款流水 bill_price 合计`（按店铺、结算周期聚合）。

## 数据来源

| 场景 | 主表 | 说明 |
|------|------|------|
| 平台经营报表 | `li_store_flow` | 按日/月聚合 PAY、REFUND 流水 |
| 店铺结算汇总 | `li_store_flow` + `li_bill` | 流水汇总 + 各状态结算单金额 |
| 支付方式汇总 | `li_store_flow` | 按 `payment_name`、日期分组 |
| 结算台账 | `li_store_flow` + `li_bill` | 待结算流水、已出账/已对账/已付款累计 |
| 商家本店汇总 | `li_store_flow` | 限定当前店铺 ID |

## 结算单状态

| 状态码 | 含义 |
|--------|------|
| OUT | 已出账 |
| CHECK | 已对账 |
| COMPLETE | 已付款 |

## 导出限制

单次导出不超过 **50,000** 行，超出时返回参数错误提示。

## 报表与结算单校验

抽样校验：取任意一张 `li_bill` 记录，对比其各金额字段与同期 `li_store_flow` 聚合结果，以及 Excel 导出汇总行，应完全一致（误差 0）。
